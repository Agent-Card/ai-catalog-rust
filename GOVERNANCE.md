# Governance

This repository is maintained by AGNTCY Contributors.

## Decision Making

- Day-to-day development happens through pull requests.
- Technical decisions should be made in the open through code review and repository discussions.
- Architectural or specification-shaping decisions should be captured in `adr/` when they materially affect the project.

## Maintainers

Maintainers review changes, request revisions, and merge approved pull requests.

## Release and Branch Policy

- `main` is the integration branch.
- Changes land through reviewed pull requests.
- Contributors should work from feature branches rather than pushing directly to `main`.
